# Better Manager

Aplicação web de gerenciamento pessoal com autenticação, perfil customizável e quadro Kanban.

## Funcionalidades

- **Tela de carregamento** — animação de entrada ao acessar o app
- **Cadastro e login** — autenticação com banco de dados PostgreSQL (Neon) e senhas criptografadas com bcrypt
- **Perfil customizável** — edição de nome, gênero, data de aniversário e foto
- **Workspace (Kanban Board)** — quadro de tarefas com colunas e cards arrastáveis, criação e exclusão de tarefas, e edição inline de títulos

## Tecnologias

- [Next.js](https://nextjs.org/)
- [PostgreSQL](https://www.postgresql.org/) via [Neon](https://neon.tech/)
- [hello-pangea/dnd](https://github.com/hello-pangea/dnd) — drag and drop
